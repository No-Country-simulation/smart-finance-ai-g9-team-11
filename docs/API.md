# API Documentation

## Overview

The Finance AI backend exposes REST endpoints responsible for receiving financial transaction lists from the client application, processing the request through Machine Learning or local fallback mechanisms, managing user accounts, and returning secure financial analyses.

Base URL (development):

```
http://localhost:8080

```

---

# Endpoints

## Analyze Financial Profile

Performs a financial analysis based on the user's transaction history, utilizing AI or local fallback processing.

### Request

**POST**

```
/analise-financeira

```

---

## Request Body

```json
[
  {
    "descricao": "Supermercado",
    "valor": 420.00,
    "tipo": "Despesa",
    "data": "2026-06-01"
  }
]

```

---

## Request Fields

The request body expects a JSON array containing a list of financial transactions.

## Transaction Object

| Field     | Type       | Required | Description                               |
|-----------|------------|----------|-------------------------------------------|
| descricao | String     | Yes      | Transaction description.                  |
| valor     | BigDecimal | Yes      | Transaction amount.                       |
| tipo      | Enum       | Yes      | Transaction type (`RECEITA` or `DESPESA`) |
| data      | Date       | Yes      | Transaction date.                         |

---

## Response

**HTTP 200**

```json
{
  "perfil_financeiro": "Em observação",
  "nivel_endividamento": 15.50,
  "frequencia_poupanca": "Média",
  "probabilidade": 0.82,
  "resumo_gastos": {
    "ALIMENTACAO": 420.00,
    "TRAJETO": 300.00
    
  },
  "recomendacoes": [
    "Monitorar gastos recorrentes.",
    "Aumentar a reserva financeira mensal."
  ]
}

```

---

## Response Fields

| Field               | Type                    | Description                                              |
|---------------------|-------------------------|----------------------------------------------------------|
| perfil_financeiro   | FinancialProfile        | Financial profile predicted by the AI or fallback rules. |
| nivel_endividamento | BigDecimal              | Calculated or provided debt level percentage.            |
| frequencia_poupanca | SavingFrequency         | Calculated or provided saving frequency.                 |
| probabilidade       | BigDecimal              | Prediction confidence score (0 for fallback).            |
| origem              | Source                  | Processing origin source (`ML` or `FALLBACK`).           |
| resumo_gastos       | Map<String, BigDecimal> | Total spending grouped by category.                      |
| recomendacoes       | List                    | Financial recommendations generated by the system.       |

---

## Analysis History Endpoints

### List Analyses

**GET** `/analises`

Returns all financial analyses associated with the authenticated user.

### Retrieve Analysis by ID

**GET** `/analises/{id}`

Returns a specific financial analysis belonging to the authenticated user.

### Delete Analysis

**DELETE** `/analises/{id}`

Deletes a specific financial analysis belonging to the authenticated user.

# Validation Rules

The backend validates all incoming requests and security constraints before processing.

### Authentication & Security

* Requests require valid JWT authentication.
* Resource access is strictly isolated by user ID (`usuarioId`) to prevent unauthorized access (IDOR).

### Transactions

* Cannot be null or empty.
* Strict 30-day editable/deletable window constraint.
* Duplicate transaction prevention based on user, description, value, and date.
* Each transaction must contain description, value, type, and date.

# HTTP Status Codes

| Status | Description                                 |
|--------|---------------------------------------------|
| 200    | Operation completed successfully            |
| 201    | Resource created successfully               |
| 400    | Invalid request or validation error         |
| 401    | Unauthorized (missing or invalid JWT token) |
| 403    | Forbidden (access denied to resource)       |
| 404    | Resource not found                          |
| 500    | Internal server error or ML service failure |

# Processing Flow

```
Client
   │
   │ POST /analise-financeira (with JWT & Transaction List)
   ▼
Spring Boot / Security
   │
   ▼
Request Validation & Ownership Check
   │
   ▼
FinancialAnalysisService
   │
   ├──► FastAPI (Machine Learning) [Success] ──► ML Prediction
   │
   └──► Local Fallback Service [Failure / Unavailable] ──► Deterministic Calculation
   │
   ▼
Persistence in MySQL (with Source Origin flag)
   │
   ▼
FinancialAnalysisResponse

```
